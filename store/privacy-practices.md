# Chrome Web Store Privacy Practices

Use these answers in the Developer Dashboard. They must remain consistent with the extension behavior and `PRIVACY.md`.

## Single purpose

Convert Turkish lira prices displayed on MediaMarkt Türkiye into a currency selected by the user.

## Data handling

- Personally identifiable information: **No**
- Health information: **No**
- Financial and payment information: **No**
- Authentication information: **No**
- Personal communications: **No**
- Location: **No**
- Web history: **No collection or transmission**
- Website content: **Processed locally** — visible price text on mediamarkt.com.tr is read only to perform the user-requested conversion and is not transmitted or retained by the developer.
- User activity: **No analytics or behavioral tracking**

## Remote requests

The extension requests exchange-rate tables and the current banner configuration over HTTPS. Standard HTTP delivery metadata may be processed by the named infrastructure providers. No page URL, product, price, or persistent user identifier is added to those requests.

## Advertising

The popup can display a clearly labeled contextual sponsored campaign. It is the same MediaMarkt-related campaign for eligible users and is not personalized, retargeted, interest-based, or selected from browsing activity. The advertiser is contacted only after the user clicks the CTA.

## Certifications

- Data is not sold.
- Data is not used or transferred for purposes unrelated to the extension's single purpose.
- Data is not used or transferred to determine creditworthiness or for lending.
- The extension complies with the Chrome Web Store User Data Policy, including Limited Use requirements.
