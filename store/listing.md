# Chrome Web Store Listing

## Product name

Price Optimizer

## Summary

Converts Turkish lira prices on MediaMarkt Türkiye into your selected currency.

## Category

Shopping

## Language

English (popup also supports Turkish)

## Detailed description

Price Optimizer makes it easier for international shoppers to understand prices on MediaMarkt Türkiye. It detects Turkish lira amounts on product, category, campaign, instalment, insurance, and dynamically loaded sections, then displays the equivalent value in the currency selected in the extension popup.

Features:

- Works exclusively on mediamarkt.com.tr.
- Supports USD, EUR, GBP, RUB, AZN, KZT, AED, SAR, CHF, UAH, and BYN.
- Handles MediaMarkt price formats such as ₺43.259,– and prices split across multiple page elements.
- Preserves the site's typography and layout.
- Uses exchange-rate data from central-bank sources when available, with an HTTPS fallback provider.
- Lets the user enable or disable conversion at any time.
- Includes an English/Turkish popup language switcher.
- Clearly labels the optional contextual sponsored banner in the popup.

Price conversion happens locally in the browser. Product names, prices, page contents, URLs, and browsing history are not sent to the developer or advertisers. The sponsored campaign is not personalized and is not selected using product information or browsing behavior.

Price Optimizer is an independent extension and is not affiliated with or endorsed by MediaMarkt. MediaMarkt names and trademarks belong to their respective owners.
