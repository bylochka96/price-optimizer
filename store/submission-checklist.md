# Chrome Web Store Submission Checklist

## Package

- [ ] Upload `dist/price-optimizer-2.3.0.zip`.
- [ ] Confirm `manifest.json` is at the ZIP root.
- [ ] Confirm the version is greater than every previously uploaded version.
- [ ] Install the exact ZIP unpacked and test on a MediaMarkt category and product page.

## Store listing

- [ ] Copy the summary and detailed description from `store/listing.md`.
- [ ] Select **Shopping** and **English**.
- [ ] Optionally add the Turkish localized listing from `store/listing-tr.md`.
- [ ] Upload `icons/icon128.png` as the 128×128 store icon.
- [ ] Upload `store/assets/screenshot-1280x800.png`.
- [ ] Upload `store/assets/small-promo-440x280.png`.
- [ ] Optionally upload `store/assets/marquee-1400x560.png`.
- [ ] Enter the homepage, privacy, and support URLs from `store/listing.md`.

## Privacy practices

- [ ] Use `store/privacy-practices.md` to complete the disclosure form.
- [ ] Use `store/permissions.md` for permission justifications.
- [ ] Certify compliance with the Chrome Web Store User Data Policy and Limited Use requirements.
- [ ] Disclose the contextual sponsored banner and remote configuration accurately.

## Distribution and review

- [ ] Choose public or trusted-testers distribution.
- [ ] Verify that the GitHub Pages privacy policy and banner JSON are publicly reachable.
- [ ] Submit for review in the Chrome Web Store Developer Dashboard.

Publishing to the Chrome Web Store itself requires the owner's registered Chrome Web Store developer account and manual dashboard confirmation.
