Price Optimizer Privacy Policy

Browser extension for MediaMarkt Türkiye price conversion

Effective date: July 27, 2026

Price Optimizer converts Turkish lira prices displayed on MediaMarkt Türkiye into a currency selected by the user. This policy explains the limited data processing required to provide that feature.

Data processed locally

Price Optimizer reads visible price text on mediamarkt.com.tr and replaces matching TRY values locally. Product names, prices, page contents, URLs, and browsing history are not sent to the developer or advertisers.

The extension stores whether conversion is enabled, the selected currency, cached exchange rates, and the expiration time of a dismissed sponsored banner. These settings remain in Chrome extension storage or Chrome Sync until changed, cleared, or the extension is removed.

Network requests

The extension makes HTTPS requests to the Central Bank of the Republic of Türkiye, Narodowy Bank Polski, the European Central Bank, and ExchangeRate-API for exchange rates, and to this GitHub Pages site for sponsored-banner configuration and an optional image.

Those services may receive standard network metadata such as IP address, user agent, request time, and requested resource. Price Optimizer does not add a persistent identifier, product information, page URL, or browsing history to these requests.

Sponsored banner

The popup may show a clearly labeled contextual sponsored banner. It is not selected using browsing history, product data, behavioral profiling, or personal information. An advertiser's site opens only after a click. Campaign-level UTM parameters do not contain a user identifier or the MediaMarkt page being viewed.

Collection, sharing, and sale

Price Optimizer does not collect analytics, build user profiles, sell personal information, or share page content or browsing activity with the developer or advertisers.

Security and retention

All network requests use HTTPS. Remote banner configuration is validated data and is never executed as JavaScript or HTML. Locally stored settings remain until the user changes them, clears extension data, or removes the extension.

Children's privacy

Price Optimizer is not directed to children and does not knowingly collect personal information from children.

Changes and contact

Material changes will be published here with a revised effective date. Questions can be submitted through the GitHub issue tracker.

Chrome Web Store Limited Use

Price Optimizer's use of information obtained through Chrome APIs complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Information is used only to provide or improve the extension's single user-facing purpose and is not used for personalized advertising.
